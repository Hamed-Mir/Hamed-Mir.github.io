# BuildPro Construction Website

Responsive, single-page construction company website built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser. The photographs are stored locally in the `images/` folder and are linked using relative paths, so no image hosting is needed.

## Project structure
- `index.html` — semantic page structure and SEO metadata
- `styles.css` — styling and mobile/tablet/desktop breakpoints
- `script.js` — mobile navigation, newsletter demo, back-to-top button
- `images/` — local image assets used by the website

## Responsive breakpoints
- Mobile: up to 760px (with a compact-phone refinement at 430px)
- Tablet: 761px–1050px
- Desktop: above 1050px

## Before publishing
Replace sample company details, phone/email, project claims, testimonials and social links with verified information. The newsletter is a front-end demo and is not connected to a mailing platform. The image assets are cropped from the visual reference generated for this project; replace them with licensed project photography for a real business website.

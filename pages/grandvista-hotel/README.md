# GrandVista Hotel & Resort

A responsive luxury hotel landing page built with semantic HTML, Tailwind CSS utilities, custom CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. Internet access is required for the Tailwind CDN, Google Fonts, and remote Unsplash images.

## Files
- `index.html` — page structure and content
- `styles.css` — custom styling and responsive refinements
- `script.js` — mobile menu and booking form interactions

## Responsive behavior
- Mobile: below 640px
- Tablet: 640px–1023px
- Desktop: 1024px and above

## Notes
This is a front-end practice project. The booking form validates dates and displays a demo confirmation; it does not create real hotel reservations. Replace demo contact details, room prices, and imagery before publishing.

For production, install Tailwind locally with its CLI or Vite instead of using the CDN.
